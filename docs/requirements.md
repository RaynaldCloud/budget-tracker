# Requirements

The API must let a user:

1. Register an account and log in
2. Create spending categories, such as Food, Transport and Rent
3. Record transactions (income or expense) with an amount, date, category and optional note
4. View, edit and delete their own transactions, and filter them by date range or category
5. Set a monthly budget for each category
6. Get a monthly summary showing spending against budget per category, flagging any category that's over budget
7. Only ever see their own data, never another user's
